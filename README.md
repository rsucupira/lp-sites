# Uebey Sites

Landing page comercial específica da Uebey para criação de landing pages, sites e experiências digitais leves.

## Posicionamento

**A place for ideas on the web.**

A página não vende tecnologia como fim. Ela vende clareza, direção, implementação e publicação.

## Oferta de entrada — Uebey Start

Preço: **R$99**.

Entrega do Sprint:

- briefing objetivo;
- diagnóstico do objetivo principal;
- estrutura recomendada;
- direção visual;
- primeiro conceito do hero / abertura;
- recomendação do próximo escopo.

Prazo indicado: **24 horas úteis**, contado somente após briefing completo e materiais mínimos recebidos.

### Crédito

Se o cliente contratar o primeiro projeto Uebey em até **7 dias corridos após a entrega do Start**, os R$99 são abatidos integralmente do primeiro pagamento do projeto.

O crédito não é conversível em dinheiro nem acumulável. O Start é uma entrega independente. Cancelamentos e reembolsos permanecem sujeitos à legislação aplicável.

## Regra de prazo

O cronograma de produção começa depois de:

1. briefing completo;
2. materiais necessários recebidos;
3. escopo aprovado;
4. condição inicial de pagamento concluída.

Isso evita interpretar “5 dias” como cinco dias contados da primeira mensagem do cliente.

## Conteúdo editável

Por padrão, Launch e sites simples podem ser estáticos. Se o cliente precisar cadastrar/retirar produtos, mudar preços ou publicar conteúdo com frequência, a camada editável (CMS, base/planilha conectada ou solução equivalente) deve ser definida e precificada no escopo.
