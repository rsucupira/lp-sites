# Sites & Landing Pages — Rodrigo de Carvalho

Landing page de portfólio e oferta de serviços para criação de landing pages, sites institucionais, portfólios profissionais, catálogos digitais e lojas enxutas com checkout externo.

## Arquivos

- `index.html` — conteúdo e estrutura
- `styles.css` — identidade visual responsiva
- `script.js` — menu, filtros do portfólio, animações e orçamento via WhatsApp
- `favicon.svg` — ícone do site

## Publicação

Projeto estático, sem etapa de build. Pode ser publicado em serviços compatíveis com HTML, CSS e JavaScript e domínio personalizado.

## Observações comerciais

Os valores exibidos são estimativas iniciais e devem ser confirmados após briefing. Integrações pagas, domínio, taxas de plataformas, marketing contínuo e sistemas complexos não estão incluídos automaticamente.
